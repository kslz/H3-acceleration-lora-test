## 评分列名说明

| 原字段 | 中文列名 | 含义 |
| --- | --- | --- |
| overall | 综合评分 | FineVQ 综合评价 |
| blur | 模糊评分 | 越高越清晰；不是模糊程度百分比 |
| noise | 噪点评分 | FineVQ 噪点维度原始输出 |
| artifact | 伪影评分 | FineVQ 伪影维度原始输出 |
| temporal | 时序一致性 | FineVQ 时间维度原始输出 |
| color | 色彩评分 | FineVQ 色彩维度原始输出 |
| technical_mean | 技术分 | DOVER 三次采样技术均值 |
| aesthetic_mean | 美学分 | DOVER 三次采样美学均值 |
| overall_mean | 综合分 | DOVER 三次采样综合均值 |

FineVQ 原始分数不换算为百分制，也不与 DOVER 相减。下表 FineVQ 保留至三位小数，以保留本轮0.125等细分值；DOVER 保留至四位小数；完整精度见 CSV 和 JSON。
